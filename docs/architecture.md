# Архитектура и границы пилота

## Поток данных

Браузер → NestJS WebSocket → приватный speech worker → подтверждённая реплика → KEV/Qwen → карточка → гибридный поиск → выбранная LLM → проверка ссылок → подсказка и AI SDK UI stream.

Клиент не получает API-ключи или адреса внутренних хранилищ. API проверяет сессию и принадлежность диалога при открытии WebSocket и периодически перепроверяет её. Администратор может читать историю сотрудников своей организации, но не вносить реплики от их имени. Смена активной организации завершает текущий разговор.

Состояние находится в `app_record` (PostgreSQL JSONB с составным ключом organization/kind/id). Обновления карточки выполняются под `SELECT FOR UPDATE`. Именованные advisory locks сериализуют создание разговоров и публикацию знаний с финальной проверкой подсказки. Better Auth использует собственные мигрируемые таблицы user/session/account/organization/member/invitation.

## Достоверность

Модель не пишет текст фактического совета: она выбирает ID из конечного набора найденных блоков. Сервер допускает только извлечённые блоки той же опубликованной версии, той же организации и региона, с действующим сроком и выполненными зависимостями. Текст и ссылка формируются из сохранённого источника. Если подходящего блока нет, показывается фиксированный отказ с просьбой уточнить запрос.

Это предотвращает добавление моделью несуществующих цен и требований. Это не доказывает правильность самого регламента, применимость выбранного фрагмента или безошибочность распознавания. Администратор должен публиковать самостоятельные короткие фрагменты, в которых сохранены условия и исключения. Ошибки классификации и выбора источника оцениваются отдельно. Для каталога указывайте дату и проверяйте остатки во внешней системе; CRM в пилоте нет.

Текст документов, речь и вопросы считаются недоверенными данными. Свободные значения карточки принимаются только при наличии точной цитаты из разрешённой реплики. Наличие цитаты не доказывает её истинность. Подтверждение выполнения шага доступно только сотруднику. LLM не выполняет операций в системах оператора.

## Ревизии и память

Новое существенное высказывание, исправление расшифровки/говорящего и ручное изменение увеличивают ревизию; результат классификации также получает новую ревизию. Генерации захватывают ревизию и эпоху, поздние результаты отбрасываются. Публикация/архивация документа отменяет применимость прежних подсказок. Новый посетитель получает новый ID, карточку и историю предложений.

В модель передаётся карточка и до шести последних разрешённых реплик. Неопределённая/перекрывающаяся речь в этот контекст не входит. Исправление реплики очищает зависимые извлечённые факты и пересчитывает классификацию. Простые эвристики используются только в явно обозначенном деморежиме.

Начальные лимиты задаются размером входных фрагментов и `maxOutputTokens`; 1 500/5 000 входных токенов — целевой бюджет, а не универсальный точный токенизатор всех моделей OpenRouter. Фактический расход возвращает провайдер. Автоподсказки ограничены интервалом 8 секунд; ручной запрос обходит интервал. Кэш 60 секунд включает организацию, диалог, карточку, модель, вопрос и версии источников. Опубликованный срочный шаг для текущего намерения обходит ожидание и выбирается сервером без вызова LLM; повторно автоматически не показывается, пока не сменится его версия.

## Аудио

AudioWorklet посылает PCM s16le mono 16 kHz блоками 100 мс. Diart работает окном 5 секунд, шагом 500 мс и задержкой стабилизации 2 секунды. Одиночная стабильная речь объединяется до паузы, смены голоса или 10 секунд и передаётся в Mistral Realtime. Такой порядок сохраняет проверку говорящего перед контекстом, но добавляет задержку по сравнению со сплошным неразделённым ASR-потоком.

При паузе микрофона сервис дополняет окно тишиной и завершает последние ASR-запросы. При аварийном обрыве часть незавершённой реплики может быть потеряна; сохранённое аудио позволяет администратору проверить её. Аудио не отправляется в OpenRouter. Вектор консультанта хранится в RAM, посетители постоянно не идентифицируются.

Первый клиент определяется по очередности относительно речи консультанта и отличию от образца голоса. Неоднозначность требует подтверждения сотрудника. Для автоматической смены посетителя сервер требует ранее обнаруженное завершение, новый голос с уверенностью ≥ 0.85, паузу и новое обращение. Текущий worker выдаёт для неизвестного голоса 0.5: до калибровки на реальных записях такая смена всегда требует выбора «текущий / новый / посторонний». Направленный микрофон важнее попыток исправить смешанный сигнал постфактум.

Один экземпляр API и один speech worker — поддерживаемая топология пилота. Redis не используется как межсерверная шина WebSocket; для горизонтального масштабирования потребуются pub/sub, маршрутизация голосовых сессий и общие отмены запросов. Обработка моделей CPU сериализована внутри worker для ограничения памяти: пропускную способность нужно измерить, GPU/реплики добавляются после профилирования.

## Хранение и регион

Аудио хранится в S3 чанками WAV примерно по 30 секунд, доступ — только через проверяемый API. Исходные записи не считаются обезличенными. Перед хранением расшифровки и передачей в OpenRouter маскируются распространённые форматы телефона, email, паспорта и длинных номеров; имена, адреса и произвольные персональные данные этим regex-фильтром полностью не обезличиваются.

BullMQ запускает удаление каждые 60 минут: разговор, аудио, карточка, ревизии и связанный usage удаляются после 30 дней. При недоступности S3 задача завершится ошибкой и должна быть повторена; без работающего worker срок не обеспечивается. Для production задайте также lifecycle 30 дней на префикс `recordings/` с учётом tenant-префиксов и политику очистки резервных копий. Документы базы знаний и аудит публикаций живут отдельно от разговоров.

В интерфейсе у документа есть регион. Базовая рабочая сессия использует «Все регионы» и поэтому не выбирает региональные условия автоматически. Консультант выбирает регион в редактировании карточки. Смена региона отменяет прежнюю генерацию и применяет новый фильтр источников.

## Проверенные первичные контракты

- [KEV 4B](https://huggingface.co/jaredpalmer/kev-4b): классификация решений; русский язык вне заявленного основного распределения обучения, требуется независимая оценка.
- [OpenRouter Decisions](https://openrouter.ai/docs/guides/features/decisions): endpoint `/api/alpha/decisions`, choice/noul.
- [Mistral Realtime](https://docs.mistral.ai/capabilities/audio_transcription/realtime_transcription): PCM и потоковые события; диаризация выполняется отдельно.
- [Diart](https://github.com/juanmc2005/diart): онлайн-разделение говорящих.
- [Weaviate Docker](https://docs.weaviate.io/deploy/installation-guides/docker-installation): самоуправляемый поисковый сервис.
- [Better Auth organizations](https://better-auth.com/docs/plugins/organization): членство и роли.
- [Document Picture-in-Picture](https://developer.chrome.com/docs/web-platform/document-picture-in-picture): отдельное окно браузера и его ограничения.
